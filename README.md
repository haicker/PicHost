# PicHost - 图片托管系统

一个轻量级的图片托管系统，支持多种存储方式。

## 功能特点

- 📤 **多存储支持**: 支持本地存储、GitHub 存储和 WebDAV 存储
- 🔒 **用户认证**: 支持登录认证功能
- 📊 **后台管理**: 提供图片管理后台，支持网格和列表视图
- 📱 **响应式设计**: 支持桌面和移动设备
- 🔗 **自动复制**: 上传成功后自动复制图片链接到剪贴板

## 存储方式

### 本地存储
- 默认存储方式
- 图片保存在服务器本地

### GitHub 存储
- 需要配置 GitHub Token
- 图片存储在 GitHub 仓库中

### WebDAV 存储
- 需要配置 WebDAV 服务器信息
- 支持任意 WebDAV 兼容服务器

## 目录结构

```
pichost/
├── admin/              # 后台管理页面
├── assets/             # 静态资源
│   ├── css/            # 样式文件
│   ├── js/             # JavaScript 文件
│   └── images/         # 图片资源
├── includes/           # 核心函数和配置
├── install.php         # 安装脚本
├── upload.php          # 上传处理
├── proxy.php           # WebDAV 代理
└── index.php           # 前台页面
```

## 使用说明

1. **上传图片**: 在前台页面选择图片并上传
2. **复制链接**: 上传成功后链接自动复制到剪贴板
3. **管理图片**: 登录后台管理查看和管理所有图片
